# Online Fuel Delivery Management System

## Project Overview
The Online Fuel Delivery Management System is a web application
developed to help users request fuel deliveries and manage orders online.

## Technologies Used
- Java
- Java Servlets
- JDBC
- MySQL
- HTML
- CSS
- JavaScript
- Apache Tomcat

## Features
- User registration and login
- Fuel order management
- Order tracking
- User profile management
- Delivery agent management
- Admin dashboard
- Feedback management

## Project Structure
- `src/main/java/` - Java source code
- `src/main/webapp/` - HTML pages and web configuration

## Database
The application uses MySQL. Database configuration and schema
instructions will be documented after deployment preparation.

## Running the Project
1. Install a compatible JDK.
2. Install Apache Tomcat.
3. Configure the MySQL database.
4. Import the project into Spring Tool Suite or Eclipse.
5. Configure the database connection.
6. Deploy the application to Tomcat.
